# ANSI Log Viewer

A VS Code extension for viewing log files with full ANSI color rendering, live tail, and regex filtering — all inside a webview panel.

## Why

VS Code's built-in text editor strips ANSI escape codes, so log files generated by colorized loggers (Python's `colorlog`, Node's `chalk`, Docker logs, etc.) show up as raw escape sequences. Opening a terminal and `tail -f`-ing the file works, but you lose the ability to filter, and the terminal is a separate context from your editor.

This extension solves that: open any `.log` file directly in the editor, see the colors, follow new output as it arrives, and filter by regex — without leaving VS Code.

## Features

- **ANSI color rendering** — converts escape codes to colored spans using [`ansi-to-html`](https://github.com/rburns/ansi-to-html). Supports standard, bright, and 256-color codes.
- **Live tail** — watches the file with `fs.watch` and appends only new bytes as they are written. Works like `tail -f`.
- **Auto-scroll control** — scrolling up manually pauses tail; re-enabling the Tail checkbox resumes it and jumps to the bottom.
- **Regex filter** — type any regex in the toolbar to show only matching lines. The filter runs against the raw (ANSI-stripped) text. Invalid patterns are flagged with a red border.
- **Log rotation aware** — detects when the file is truncated (e.g. `logrotate`) and reloads from scratch.
- **`Ctrl+F`** — focuses the filter input from the keyboard.

## Usage

**From the Explorer** (right-click any `.log` or `.txt` file):

> Log Viewer: Open in Log Viewer

**From the Command Palette** (`Ctrl+Shift+P`):

> Log Viewer: Open in Log Viewer → file picker opens

Multiple panels can be open simultaneously, one per file.

## Installation

### From source (dev mode)

```bash
git clone git@github.com:italocjs/ansi-log-viewer.git
cd ansi-log-viewer
npm install
```

Press **F5** in VS Code to launch an Extension Development Host.

### As a `.vsix` (permanent install)

```bash
npm run package          # compiles + generates ansi-log-viewer-x.x.x.vsix
npm run install-ext      # installs into VS Code
```

Or install manually:

```
code --install-extension ansi-log-viewer-0.1.0.vsix
```

## Project structure

```
src/

  logViewerPanel.ts  — webview panel: file reading, fs.watch tail, HTML/CSS/JS

tsconfig.json
.vscodeignore        — controls what goes into the .vsix
```
